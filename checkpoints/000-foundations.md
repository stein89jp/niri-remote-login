# Foundation checkpoint — 2026-10-10

Scope: produce artifacts for a separate Arch Linux Niri installation. The user
explicitly prohibits installation on the working host. GNOME Remote Login,
packages, accounts, system services, PAM and power settings remain untouched.

Repository metadata is unavailable: the supplied `.git` directory is an empty
read-only placeholder. Checkpoints therefore use Markdown decision records and
SHA-256 inventories generated by `scripts/checkpoint.py`, rather than pretending
to create Git commits.

Separate agent ownership: compositor and disposable lab (`compositor/`, `lab/`),
Wayland/RDP adapter (`bridge/`), PAM/logind broker (`broker/`). The coordinator
owns packaging, cross-component verification and top-level documentation.

Baseline dependency revisions remain in `research/upstream/manifest.json` and
`poc/Cargo.lock`. The synthetic PoC uses crates.io ironrdp-server **0.13.0**.
The login bridge requires authentication/binding APIs absent from that published
release; it is evaluating the already researched development revision
`bf019ca502d1e52616853a5ded68c885cec1e322`. No custom RDP protocol is authorized.

Executed baseline checks:

```sh
python3 -m unittest discover -s tests -v
CARGO_HOME="$PWD/poc/.cargo-cache" cargo test --locked --offline --manifest-path poc/Cargo.toml
python3 poc/tests/startup.py
POC_RDP_BINARY="$PWD/poc/target/debug/niri-rdp-transport-poc" python3 -m unittest tests.test_rdp_transport -v
```

Results: seven isolation tests, five Rust tests, four startup rejection tests,
and one FreeRDP synthetic transport test pass. Default unittest discovery skips
the opt-in transport test. Initial sandbox execution denied private D-Bus
sockets; an authorized execution outside that sandbox passed the unchanged
suite. A `/proc` child-exit race occurred in that first restricted run but did
not reproduce in the permitted run. Temporary loopback transport artifacts and
children were cleaned up by the test.

Disposable namespace capability check passes outside the execution sandbox:

```sh
bwrap --unshare-all --die-with-parent --ro-bind /usr /usr \
  --symlink usr/lib /lib --symlink usr/lib /lib64 \
  --ro-bind /etc/os-release /etc/os-release --proc /proc \
  --dev /dev --tmpfs /tmp /usr/bin/true
```

This provides read-only Arch userspace and private devices/network. It does not
provide an independent systemd/logind boot and cannot satisfy the boot gate.
No QEMU, Docker, Podman or devtools clean-chroot command is available. Installing
those on the host is prohibited; prepare reproducible separate-machine checks.

Remaining gates: actual headless changing-pixel capture, virtual input into an
application, authenticated PAM/logind lifetime, package build/inspection,
Windows mstsc, cold boot without local login, physical-monitor-off/disconnect,
failure and crash cleanup. Do not claim these from the synthetic PoC.
